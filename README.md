## 你的 Agent，跟着你的想法走

灵感未必出现在电脑前。它可能来自沙发上的一次闲聊、会议里的一段讨论，或准备出门时突然冒出的念头。

**Fenno Air 是随你而行的个人 Agent。想到什么，开口交代；做到哪了，随时问一句；方向变了，再补充一句。** 从书桌到客厅，从一个人的灵感到一群人的讨论，让 Agent 跟上你的节奏。

## 聊懂了，就一起动手

编程，是 Fenno Air 首先打磨的协作场景。

“帮我做个网页。”“继续昨天的项目。”“按钮换成绿色，其他功能保留。”你说出目标，云端编程 Agent 读取代码、动手修改、运行测试；你可以随时询问进度、调整方向，再看着结果继续完善。

我们希望你也能选择合拍的编程搭档：让 Claude Code 或 Codex 执行任务，把你偏好的编程工具接入这段对话。当前原型已接通 Claude Code；Claude Code／Codex 的选择能力按 [运行时选择规划](https://github.com/wwcchh0123/hackathonGO-2026/issues/29) 推进。

## 有个想法？让它在眼前长出来

**已有 GitHub 项目，想把一个问题推进到可评审的 PR。**
“在我的 GitHub 仓库开个 Issue，记录登录失败的问题，按这个 Issue 修复，补上测试后提交 PR。”让 Fenno 接手现有代码，围绕 Issue 定位问题、实现修改、运行测试，把改动与验证结果交到 PR；你再审查代码、提出反馈，继续推进。

**窝在沙发上，想到一个全家都能用的小工具。**
“帮我做份旅行清单。”把它投到客厅电视上，和家人一起添添改改，试出大家都喜欢的样子。

**开会聊到一个点子，想马上看一眼。**
“把刚才的想法做成网页。”借会议室的大屏，把抽象的讨论变成眼前可以一起看、一起试的原型。

**陪孩子琢磨一个游戏，想边玩边弄明白。**
“做一个双人井字棋。”让它出现在屏幕上，一起试着落子，再问一句：“它是怎么判断谁赢的？”

**你带着想法，Fenno 陪你动手；借身边的一块屏幕，让大家都看得见。**

## 你可以交给它什么

- **从想法开始**：“帮我做一个能开始、暂停和重置的番茄钟。”创建独立任务，查看真实执行事件和导出的网页。
- **让作品继续长大**：“加上截止日期，保留之前的数据。”在原任务中补充需求、修改和继续。
- **推进已有 GitHub 仓库**：“在这个仓库开个 Issue，修复登录问题，跑测试后提交 PR。”在现有项目上完成问题记录、代码修改、测试和 PR 交付，供你审查与继续反馈。
- **找回之前的工作**：“看看上一个任务做到哪了。”列出历史任务，查看状态，继续兼容的云端会话。
- **同时推进不同想法**：“再开一个任务做产品介绍页。”新建任务与切换画面不会停止其他任务。
- **按你的节奏观看**：查询进度、切换任务、滚动展示或停止投屏；停止播报和停止投屏各自独立，不会停止云端编程任务。

GitHub 场景需要预先配置目标仓库的访问与写入授权，见 [部署指南](docs/deploy.md#真实-agentapi)。

## 先体验本地模拟

需要 Go 1.26+。克隆仓库后，在项目目录运行：

```sh
make install
make dev
```

打开 [模拟控制台](http://localhost:8080/simulator)，点击“新建独立任务”，选择展示任务，等待事件和结果出现。也可以另开 [模拟设备页](http://localhost:8080/device)，体验“展示 A、修改 B”的独立操作。[管理页](http://localhost:8080/admin) 可只读查看设备与任务。

这个模式无需云端密钥、麦克风或 AirPlay，使用固定番茄钟模板模拟执行，**不会实际生成代码**。

## 使用真实语音与 AI 编程

完整体验需要灵矽账号与已绑定的语音设备、可用的 AgentAPI agent/environment、控制服务公网 HTTPS 地址，以及可用的显示终端。

1. 按 [部署指南](docs/deploy.md) 配置真实 AgentAPI 和两个 MCP 服务。
2. 在 Mac 上运行语音终端：

   ```sh
   brew install opus pkgconf
   make voice
   ```

3. 打开 [语音页面](http://127.0.0.1:8090)，首次使用按页面激活码在灵矽智控台绑定设备，然后点击“连接智能体”。完整步骤见 [语音指南](docs/voice.md)。
4. 点击“开始说话”，说出需求，再点击“说完了，发送”。智能体调用编程工具，设备打开任务展示页；配置兼容的 AirPlay 接收端后，可投到大屏。

**当前仓库提供软件原型**：Mac 语音终端、控制服务和设备浏览器投屏程序。最终硬件形态尚未定型；“借大屏远程编程”是产品体验方向，当前搭建与演示仍需要计算机。语音交互需要手动开始和结束录音，每轮最多 60 秒。保存角色或工具配置后，应断开并重新连接语音设备。
