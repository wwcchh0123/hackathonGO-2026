# 当前正面小狐狸

`front.png` 为用户确认的正面形象，参考 [Fenno 首页](https://api.fenno.ai/home) 的蓝紫色小狐狸，使用 Fenno API 的 `gpt-image-2` 在 2026-10-25 生成，再移除纯色背景得到透明 PNG。图像尺寸为 1024 × 1536，生成质量为 high。绘制要求为全身正面、双眼直视用户，保留蓝紫色毛发、白色胸口及蓬松尾巴。这里保留用户确认的 PNG，不进行二次位图绘制。

人物页面通过 SVG 裁剪同一张原图组合身体与头部，叠加矢量眼睑及嘴型，以 CSS 实现眨眼、呼吸和歪头；嘴型由现有语音播放音量驱动。素材随程序本地提供。
