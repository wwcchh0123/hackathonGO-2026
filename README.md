# 灵矽语音编程工作站

[![CI](https://github.com/wwcchh0123/hackathonGO-2026/actions/workflows/ci.yml/badge.svg)](https://github.com/wwcchh0123/hackathonGO-2026/actions/workflows/ci.yml)

说出想做的作品，在大屏上看编程智能体执行，再用语音继续修改。

灵矽负责听懂需求和语音回复，七牛 AgentAPI 中的 Claude Code 负责云端编程，本项目连接语音、编程任务和结果展示。适合课堂演示、会议中的原型讨论，以及希望通过对话快速验证想法的用户。现场终端负责收音和显示，开发环境运行在云端。

当前提供 Mac 软件语音终端、Go 控制服务和设备浏览器投屏程序。物理硬件尚未定型；Mac 和设备模拟程序用于体验与联调。

## 可以做什么

- 创建独立编程任务，在大屏查看真实消息、工具调用和执行结果。
- 在原任务继续提需求；运行中修改会先等待旧一轮停止，再发送新需求。
- 找回历史任务，切换展示；新建任务和切换画面不会停止其他任务。
- 预览智能体导出的静态网页，在同一任务的新版本中保留当前浏览器的作品数据。
- 分别停止语音播报或投屏；这些操作不会停止云端编程任务。

例如：“做一个能保存数据的待办清单” → 查看生成结果 → “加上截止日期，保留已有数据” → 在原任务中继续。

## 先体验本地模拟

需要 Go 1.26+。克隆仓库后，在项目目录运行：

```sh
make install
make dev
```

打开 [模拟控制台](http://localhost:8080/simulator)，点击“新建独立任务”，选择展示任务，等待事件和结果出现。也可以另开 [模拟设备页](http://localhost:8080/device)，体验“展示 A、修改 B”的独立操作。[管理页](http://localhost:8080/admin) 可只读查看设备与任务。

这个模式无需云端密钥、麦克风或 AirPlay，使用固定番茄钟模板模拟执行，**不会实际生成代码**。

## 使用真实语音与 AI 编程

完整体验需要灵矽账号与已绑定的语音设备、可用的 AgentAPI agent/environment、控制服务公网 HTTPS 地址，以及可用的显示终端。

1. 按 [部署指南](docs/deploy.md) 配置真实 AgentAPI 和两个 MCP 服务。
2. 在 Mac 上运行语音终端：

   ```sh
   brew install opus pkgconf
   make voice
   ```

3. 打开 [语音页面](http://127.0.0.1:8090)，首次使用按页面激活码在灵矽智控台绑定设备，然后点击“连接智能体”。完整步骤见 [语音指南](docs/voice.md)。
4. 点击“开始说话”，说出需求，再点击“说完了，发送”。智能体调用编程工具，设备打开任务展示页；有 AirPlay 接收端时可投到大屏。

当前语音交互需要手动开始和结束录音，每轮最多 60 秒。保存角色或工具配置后，应断开并重新连接语音设备。

## 使用范围

结果预览支持静态 HTML、CSS、JS 和图片，不代理任意后端端口。作品可在浏览器内交互并保存受限本地数据，不能访问外部 API 或提交真实表单。需要框架的作品应先在云端完成构建，再导出静态文件。

“已受理”表示需求排队，“输入已接受”表示上游收到需求，“本轮结束”仍需结合回复、停止原因和实际产物判断。服务重启后需要重新列出历史任务；不会自动重发旧需求。

自动测试、真实 AgentAPI 软件验证和物理声画验证分别记录，完整链路尚有未验项。当前可核对的结果、用户价值假设和演示验收步骤见 [评估与验证说明](docs/evaluation.md)。
